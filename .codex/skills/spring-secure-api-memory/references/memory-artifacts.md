# Memory Artifacts

The skill uses `.codex/project-memory/` at the repo root.

## Files

- `project-memory.md`
  - Human-readable summary of the project.
  - Update this after reading important changes or after editing the repo.

- `state.json`
  - Baseline snapshot of relevant files.
  - Generated by `scripts/sync_memory.py save`.

- `last-delta.json`
  - Comparison between the current repo state and `state.json`.
  - Generated by `scripts/sync_memory.py delta`.

## Expected Usage

1. Read `project-memory.md`.
2. Run the delta script.
3. Read only changed files and directly affected files.
4. Update `project-memory.md`.
5. Save the new snapshot.

## Scope

The snapshot tracks source, config, Maven, shell, and Markdown files that are useful for reasoning about the project.
It ignores generated or noisy directories such as `.git`, `.idea`, `target`, and `.codex/project-memory`.
